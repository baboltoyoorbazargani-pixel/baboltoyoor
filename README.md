# سامانهٔ هوشمند بابل طیور — نسخهٔ ۳۷٫۳۷٫۰

سامانهٔ عملیات بابل طیور: نگهبانی (ثبت ورود/کنترل خروج)، فروش (سفارش عادی و فروشگاهی، تسویه)، فروشگاه (ثبت سفارش و پیگیری)، انبار (ورودی، آماده‌سازی و سرویس‌های ارسال، سوابق و گزارشات) و رانندگان/پیک‌ها.

## اجرا
- نیازمندی: ‎Node.js 20+‎ — بدون هیچ وابستگی خارجی (‏`npm install`‏ لازم نیست).
- شروع: ‏`node server.js`‏
- متغیرهای محیطی: ‏`PORT`‏ (پیش‌فرض ۳۰۰۰)، ‏`HOST`‏، ‏`DATA_DIR`‏ (پوشهٔ دیتابیس؛ پیش‌فرض ‎`data/`‎ کنار پروژه)، ‏`ADMIN_INITIAL_PASSWORD`‏ (رمز اولیهٔ مدیر در اولین ساخت دیتابیس؛ مدیر در اولین ورود باید رمزش را عوض کند).
- روی ویندوز سرور: ‏`scripts/start.ps1`‏ یا ‏`scripts/start-hidden.ps1`‏؛ راهنمای استقرار: ‏`docs/deployment-windows-server-2025.md`‏.
- پل باسکول (نمایشگر ‎PU 850‎): ‏`node scripts/weighbridge-bridge.js --port COM3 --baud 9600 --server http://127.0.0.1 --token <TOKEN>`‏ — مستند پروتکل: ‏`docs/weighbridge-pu850.md`‏.

## شروع از صفر (دیتای خام)
پوشهٔ ‎`fresh-data/`‎ (تحویل جدا، کنار این بسته) یک دیتابیس خام آماده است: فقط مدیر سامانه + کاتالوگ پیش‌فرض محصولات؛ بدون کاربر، مشتری یا سفارش.
کافی است آن را به‌عنوان ‏`DATA_DIR`‏ بدهید و سرویس را بالا بیاورید؛ با کاربر ‏`admin`‏ و رمز اولیه‌ای که در یادداشت همان پوشه آمده وارد شوید (سامانه در اولین ورود تعویض رمز را اجباری می‌کند)، بعد کاربران هر نقش را از پنل مدیریت بسازید.
